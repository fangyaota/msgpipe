# 使用说明

## 一句话触发

对我说「更新待办」「生成今天的待办」「跑一下待办」「整理微信消息」「汇总最近要办的事」，我就跑完整流程。不带「微信」两个字也行，只要语境是待办、通知、截止日期，就走这条链路。

## 入口与前提

日常统一走 `<项目目录>\scripts\msgscan.cmd`：

```bash
msgscan.cmd sources                               # 四线自检
msgscan.cmd sessions --since "2026-11-14 22:03"   # 哪些会话有更新
msgscan.cmd since --at "2026-11-14 22:03"         # 断点后的全部消息
msgscan.cmd search "关键词" --since "2026-11-01"    # 跨线检索
msgscan.cmd assignments                           # 学习通与数你最灵的作业状态
msgscan.cmd chapters --course 工程图学              # 章节里的作业（纸面作业清单）
msgscan.cmd inbox --limit 20                      # 学习通站内信
msgscan.cmd advance --at "2026-11-15 15:00"       # 干完推水位
```

前提五条。微信客户端要开着，密钥只在运行时取得；学习通消息走 `<项目目录>\tools\cxmcp`（Node + Edge，登录态在它的 user-profile 里，失效就重灌一次 cookie）；滴答清单的 MCP 已经接好，重启后自动加载；企业微信的 key 存在 `<项目目录>\state\wecom\key.txt`，大版本升级后失效，重抓要你点一次弹窗；学习通的登录态加密存在 `<项目目录>\state\xxt`，失效时我会让你扫一次码。数你最灵不用你管，每轮都会开一个看得见的浏览器窗口约十秒。

## 我会做什么

扫全部会话挑出有事要办的，逐条读原文；通知是长图或截图、里面有时间地点的，我会读图把要求写进任务正文；座位表、名单这类不逐字读；按「<校区> + <职务>」的身份过滤，点名班长、文艺委员、宣传部、部门负责人、全体班委的不派给你，写「自愿参加」的按可选登记；生成今日待办、待办总表、日期纪要、原文四份文件；去重后同步进滴答清单收件箱，每条一个截止日期、正文末尾附原文；新文件分类归档；最后回报新建几条、勾掉几条、排除重复几条。

## 结果在哪看

手机看滴答清单收件箱，电脑看 `<项目目录>\待办\` 里的文件，原文在 `原始消息\` 子目录，随时可以核对我说得对不对。

## 还能这样问

| 你说 | 我做什么 |
| --- | --- |
| 只看最近三天有什么要办的 | 缩小窗口，只出这三天 |
| 同步到滴答 | 不重扫，只把本地清单同步 |
| 这条做完了 | 勾掉对应任务，本地打勾 |
| 帮我加一条 XX，几号前 | 手动建一条，本地与滴答都写 |
| 查一下群里关于体测的消息 | 只检索，不生成待办 |
| 体测那条的原文是什么 | 翻出原文照抄 |

## 让它自己跑

说「每天早八点自动跑一次待办」，我会建定时提醒。前提是那会儿 DSH 在运行、电脑不休眠。

## 出问题先看这里

| 现象 | 怎么办 |
| --- | --- |
| 报「未能检测到微信数据目录」 | 先确认微信在运行，再让我重跑初始化 |
| 报密钥提取失败 | 重跑 `wxcli.cmd init`，看是不是 18/18 |
| 滴答报 401 | 令牌失效，去开发者页面重新生成给我 |
| 某个群读不出消息 | 目前已知两个，得你自己点开看 |
| 链接与小程序卡片没标题 | 微信单独加密存放，只能看到占位 |
| 企微报 key 失效 | 我弹一次 UAC，你点「是」后自动重抓 |
| 企微会话寥寥无几 | 正常，它本地只留近期少量会话 |

## 待你亲手处理

有几类消息读不出来，需要本人过目：一是<群名>里转不成文字的语音；二是个别会话取不到历史（本次遇到一个观众群），可能含集合时间变更。

门户通知（`msgscan notices`）读的是学校信息门户的校级/部门级通知公告，需要浏览器里登录过 my.muc.edu.cn；它只解决「校级通知看不到」，课表成绩不在里面。
- 看群里的图片内容：`python entry.py images "<群名>" --decrypt --out <目录>`（在 `tools/wechat-cli` 下跑，先 `--key scan` 抓一次密钥）
